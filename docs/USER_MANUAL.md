# RustNotePad 使用手冊

歡迎使用 RustNotePad，這是一款基於 Rust 開發的高效能文字編輯器。

## 主要功能

### 1. 檔案管理 (File)
- **新增**: 建立新的文件分頁。
- **開啟**: 從磁碟開啟現有檔案。
- **儲存 / 另存新檔**: 儲存目前編輯的內容。
- **全部儲存**: 一鍵儲存所有開啟的文件。
- **列印預覽**: 預覽文件列印效果。

### 2. 編輯功能 (Edit)
- **復原 / 重做**: 標準的編輯歷史管理。
- **剪下 / 複製 / 貼上**: 標準剪貼簿操作。
- **全選**: 選取目前文件夾所有文字。
- **欄編輯器**: 支援多行欄式編輯。

### 3. 搜尋與取代 (Search)
- **尋找**: 支援一般文字與正規表達式搜尋。
- **取代**: 支援單一取代與全部取代。
- **在檔案中尋找**: 在整個工作區或資料夾中搜尋文字。
- **書籤**: 標記重要行號以便快速跳轉。

### 4. 檢視與介面 (View)
- **全螢幕**: 切換無干擾編輯模式。
- **視圖 (Document Map)**: 右側縮圖導覽。
- **函式清單**: 自動解析程式碼中的函式定義。
- **檔案瀏覽**: 管理工作區檔案結構。
- **狀態列 / 底部面板**: 顯示游標資訊、搜尋結果、執行輸出等。

### 5. 工具 (Tools)
- **MD5 / SHA-256**: 計算並複製內容的雜湊值。
- **開啟命令提示字元**: 在目前工作目錄開啟终端。
- **簡轉繁**: 將簡體中文內容轉換為正體中文。

### 6. 使用手冊 (Help)
- **使用手冊**: 即您現在閱讀的這份文件。
- **關於**: 顯示程式版本與開發資訊。

## 佈景主題 (Themes)
您可以透過「樣式設定器」選擇不同的佈景主題，包括 Dark+ (VS Code 風格)、Monokai、GitHub Light 等。
